# AI Workspace Local 0.5.0-beta.9 (pre-release)

- Ricerca web configurabile, allegati in chat, documenti/RAG e gateway embedding.
- Client MCP esteso, A2A in streaming e nuovi strumenti browser.
- Canali Telegram, Slack ed email; connettore IMAP in sola lettura.
- Voce neurale Piper/server compatibile OpenAI e router automatico dei runtime con fallback.
- Token per dispositivo/app, revoca, TLS LAN e sandbox rafforzata.
- Interfaccia italiano/inglese, font offline, backup/ripristino e diagnostica.
- Test E2E/accessibilità, benchmark e build arm64/CUDA opzionali.
- Corrette la dipendenza dei test dalla memoria del runner e la ricerca dell’helper Foundation Models nel pacchetto Mac App Store.

## Distribuzione e verifiche

Build store **5011**: iOS e macOS su TestFlight, Android sul track alpha. Gli upload partono automaticamente dal tag, insieme alle build desktop per GitHub Releases.

Sul codice precedente al solo incremento versione sono riusciti test core macOS/Windows, DMG universale, installer Windows e pacchetti store firmati IPA, PKG e AAB. La compilazione non sostituisce i test con dispositivi, modelli e servizi reali. I canali e diversi backend richiedono ancora tale validazione.

## Aggiornamento

Rifare il pairing per ottenere token dispositivo revocabili. Configurare TLS per l’accesso LAN cifrato. I backup escludono modelli e, di default, segreti; il ripristino richiede il daemon fermo. Consultare docs/STATUS.md per i limiti delle singole funzioni.
