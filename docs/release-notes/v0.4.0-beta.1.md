# AI Workspace Local 0.4.0-beta.1

Prima beta pubblica della serie 0.4. È una **pre-release**: le funzioni principali sono complete e
testate, ma le build non sono firmate e diversi percorsi nativi non sono ancora stati provati su
hardware reale (vedi "Limiti noti").

## Novità

- **Model hub multi-provider**: ricerca e download da Hugging Face (GGUF con shard e `mmproj`,
  repository MLX/safetensors, cartelle ONNX GenAI), ModelScope (best effort), registry Ollama e URL
  diretto con sha256 opzionale. Scansione in sola lettura dei modelli già presenti in Ollama,
  LM Studio e nella cache HF. Downloader con coda, ripresa (`Range` / `If-Range`), verifica sha256
  in streaming, controllo dello spazio disco, retry con backoff, annullamento ed eliminazione.
- **Livelli di inferenza**: il motore llama.cpp in-process viene registrato anche con le feature
  Metal, CUDA e Vulkan (su macOS e iOS prima non partiva); contesto del profilo rispettato,
  supporto a Ollama, probe hardware più accurato (VRAM su Windows, memoria unificata), vLLM e SGLang
  con `--served-model-name`, un solo avvio per runtime anche con richieste concorrenti.
- **Sicurezza dell'API locale e dei tool**: CORS ristretto, token legato all'origine, niente più
  richieste da loopback senza token che potessero registrare hook o server MCP stdio; configurazione
  del workspace ristretta, workflow del workspace disattivati, protezione dai symlink nelle radici
  di lettura, limiti di 5 MB per `web_fetch` e 16 MB per `read_file`, header anti-framing.
- **Agent loop**: prompt bloccati da hook non inviati al modello, conferme ritirate, un run per
  sessione, run interrotti segnati come falliti all'avvio, profilo di ripiego del gateway.
- **Nuova UI**: struttura per dominio, TanStack Query, router su hash con parametri, nuova
  architettura dell'informazione (Panoramica, Capacità, Integrazioni, Sicurezza), palette comandi
  Ctrl/Cmd+K, contrasto AA nei due temi, layout corretti su telefono e tablet. Errori dei run salvati
  mostrati come quelli dal vivo, segreti MCP mascherati.
- **Qualità**: test Rust da 82 a 345, test UI da 0 a 591 (Vitest) più uno smoke test Playwright
  (29 rotte × 2 larghezze × 2 temi). Correzioni per Windows nei percorsi dei modelli.

Dettagli per layer in [docs/STATUS.md](../STATUS.md) (§1 sintesi, §2 copertura).

## File della release

| Piattaforma | File |
|---|---|
| Linux x64 | `.deb`, `.rpm`, `.AppImage` |
| Windows x64 | `.msi` (versione MSI 0.4.0.1) e installer `.exe` (NSIS) |
| macOS (universale Intel + Apple Silicon) | `.dmg` (contiene l'`.app`) |
| Android | APK **arm64** non firmato: `aiw-0.4.0-beta.1-android-arm64-unsigned.apk` |
| iOS | **nessun file installabile**: la CI compila solo per il simulatore |
| Daemon `aiw` (CLI) | `aiw-0.4.0-beta.1-linux-x64`, `-windows-x64.exe`, `-macos-arm64` (Metal), con llama.cpp embedded |
| Daemon `aiw` con Vulkan (opzionale) | `aiw-0.4.0-beta.1-linux-x64-vulkan`, `-windows-x64-vulkan.exe` |

Le build Vulkan sono sperimentali e non bloccanti: possono mancare dalla release. CUDA non è
costruito in CI (compilazione locale con `--features llama-cuda`). `SHA256SUMS.txt` elenca i
checksum di tutti i file.

## Build non firmate e non notarizzate

- **macOS**: l'app non è firmata né notarizzata. Al primo avvio usa tasto destro → **Apri** → Apri,
  oppure rimuovi la quarantena:
  `xattr -dr com.apple.quarantine "/Applications/AI Workspace Local.app"`.
  Per il daemon: `chmod +x aiw-0.4.0-beta.1-macos-arm64 && xattr -d com.apple.quarantine aiw-0.4.0-beta.1-macos-arm64`.
- **Windows**: SmartScreen mostrerà "Windows ha protetto il PC": scegli **Ulteriori informazioni** →
  **Esegui comunque**.
- **Linux**: `chmod +x` su AppImage e daemon; nessuna firma dei pacchetti.
- **Android**: abilita l'installazione da origini sconosciute; l'APK non è firmato per il rilascio.

## Limiti noti

Elenco completo in [docs/STATUS.md §2.9](../STATUS.md). In sintesi: policy di rete del browser
verificata dopo la navigazione; SSRF più debole dietro un proxy HTTP; rete della shell aperta di
default; server MCP stdio fuori dalla sandbox; un solo token API condiviso senza revoca; endpoint
HF, ModelScope e Ollama mai raggiunti dall'ambiente di sviluppo (test con server locali finti);
build GPU e percorsi nativi Apple e Android non provati su hardware reale. Non costruiti: Windows
arm64, Linux arm64, Android x86_64/armv7. Computer-use assente su Linux e Android.
